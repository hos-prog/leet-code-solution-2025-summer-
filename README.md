## About

This repository contains my solutions to a wide variety of **LeetCode** problems, solved as part of the **2025 Summer** coding bootcamp at MSJ / ASTU.  
It’s a snapshot of my progress, showing how I tackled algorithmic challenges — from easy to medium/hard — and how my problem-solving skills improved over time.

Each solution is implemented (mostly in Python, possibly others) with clarity, comments, and sometimes alternative approaches or optimizations.

## Repository Structure

- **Each folder or file** corresponds to one LeetCode problem  
- Problem titles are used as folder/file names for clarity  
- Within each, you’ll usually find:
  - the solution file (`.py`, etc.)
  - comments explaining logic, edge cases, complexity
  - sometimes test cases or examples in docstrings
